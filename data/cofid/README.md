# CoFID source workbook

Download (do **not** use the separate “old foods” file):

https://assets.publishing.service.gov.uk/media/60538b91e90e07527df82ae4/McCance_Widdowsons_Composition_of_Foods_Integrated_Dataset_2021..xlsx

Save as `CoFID_2021.xlsx` in this directory, then:

```bash
npm run starter-pack:generate
```

The generated pack under `src/data/starter-pack/` is committed; this `.xlsx` is gitignored.
